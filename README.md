# Консольное приложение "Буквы"
## Способы отладки Microsoft Visual Studio, которые мы использовали в задании:
1. точки останова;
2. навигация по коду с помощью F10 (Шаг с обходом);
3. навигация по коду с помощью F11 (Шаг внутрь);
4. горячая перезагрузка;
5. наведение курсора на переменные для просмотра их значений;
6. окна переменных;
7. окно "Просмотр";
8. окно "Стек вызовов".
